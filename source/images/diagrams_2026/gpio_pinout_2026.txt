DIAGRAM: gpio_pinout_2026.svg
INTENDED CONTENT — what this diagram should show:

The standard Raspberry Pi 40-pin GPIO header, physical top view, pin 1
at top-left. Two columns of 20 pins each (column A = odd pins 1-39 top
to bottom on the left, column B = even pins 2-40 top to bottom on the
right), drawn as numbered circles inside a beige "header body" rectangle.

Each pin is colored by function and labeled on the outside edge with
its BCM name:
  - red = 5V, orange = 3.3V, dark navy = GND
  - green = I2C (GPIO2/SDA1, GPIO3/SCL1)
  - blue = UART (GPIO14/TXD0, GPIO15/RXD0)
  - dark cyan = SPI (GPIO7-11)
  - gray = ID EEPROM reserved pins (GPIO0/GPIO1 — pins 27/28)
  - teal = plain digital GPIO (everything else)
  - purple, WITH an extra dashed ring around the pin = hardware PWM
    (GPIO12, GPIO13, GPIO18, GPIO19 — pins 32, 33, 12, 35)

All 40 pins are generated programmatically from a lookup table matching
the standard, publicly documented Raspberry Pi 40-pin header (identical
across Pi Zero W/2W, 3, 4, 5, 400) — this is NOT board-specific and
should not need per-board changes.

A legend above the header explains all 9 color categories.

Below the header, two caption lines connect the diagram to
de_rpi_gpio's actual config fields:
  1. "de_rpi_gpio config: GPIO_ACTION_PORT_CONFIG selects a pin by BCM
     number (field 'p') and a mode (field 'm')"
  2. "Digital pins support PORT_WRITE (on/off); the dashed-ring pins
     (12, 13, 18, 19) additionally support hardware PWM (duty width via
     field 'd')"

SOURCE OF TRUTH:
